# 产品功能

## 文件预览

- HTML 与 HTM 文件通过主应用同源 `/preview/...` 路由全页预览，不再跳转到独立预览源，也不再包裹预览弹窗、iframe、标题栏或关闭按钮。
- 预览响应不添加限制脚本、网络请求或外部资源的 CSP，适用于可信内网 HTML。
- 同目录相对资源通过预览路由加载，包括 JavaScript、JSX、TypeScript、CSS、图片、字体、音视频和同目录 HTML。
- JSX 文件扩展名 `.jsx` 可作为预览资源加载；HTML 中使用 Babel standalone 等运行时转换 JSX 时，运行时脚本必须能被浏览器访问。
- 由于预览 HTML 与文件浏览器同源，预览内容可以访问父页面和同源接口；只应预览可信 HTML。

## 文件上传

- 上传区只有一个入口：点击入口选择普通文件上传，拖拽文件或文件夹到同一区域时自动识别并上传。
- 拖拽文件夹时，前端递归读取目录内容并通过 `relative_paths` 保留相对路径。
